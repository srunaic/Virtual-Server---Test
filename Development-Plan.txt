# Angel Kitty (천사 냥이) - Visual Novel Game Development Plan
## Project Overview
**Genre:** Visual Novel (VN)
**Platform:** Unity Engine based PC Game
**Target:** Gamers who enjoy emotional stories
**Theme:** Contract between angel and human, weight of love and choice

## World Setting
### Divine Realm (World of Gods)
- **Direct Intervention Prohibited:** Gods only observe the earth
- **Area Division:** Human Area, Angel Area, God Area
- **God Classification:**
  - Angel Management God: Manages angel order
  - God who manages human life and order
  - God who manages animal life and order

### Demon Realm (Irregular World)
- **Demon King:** Maintains order through force and survival of the fittest
- **Class System:** Demons (fallen angels), Monsters (fallen animals)

### Angel Kitty
- **Definition:** Small guardian angels created by god who manages animal order
- **Characteristics:** Can be demoted to earth if mission fails or develops emotions
- **Ability:** Can contract as guardian to specific humans/creatures

## Main Characters
### Lumi (Angel Kitty → Earth Demotion)
- **Personality:** Initially bureaucratic, gradually develops emotions
- **Abilities:** Life maintenance assistance, slows disease progression
- **Weakness:** Love emotion = violation of divine realm rules

### Male Protagonist (Human)
- **Setting:** Terminally ill young man with lung cancer, lives alone, cat lover
- **Personality:** Quiet and gentle
- **Characteristics:** Takes responsibility for cats until the end, worries about others before himself

## Core Systems
### Guardian Contract Rules
- **Condition:** Human must not have given up the will to live
- **Form:** Automatic establishment when lives choose each other (no explanation/spell)
- **Price:** Other lives are consumed as much as lives are maintained (balance maintenance)

### Meaning of Emotions
- **Angel's Perspective:** Emotion = Favoritism = Possibility of order collapse
- **Lumi's Logic:** "Having emotions doesn't necessarily destroy order. You can also choose to protect it."

## 4. Scenario Engine Development (ScriptableObject)
### Goal
Build system to manage dialogue data like Excel without code modification.

### Main Tasks
- ✅ Create DialogueData ScriptableObject
  - Data structure per dialogue line
  - Character info, text, sprites, effects, etc.
- ✅ Implement NarrativeManager
  - Load dialogue data and control progress
  - Event system (start/end/complete callbacks)
- ✅ Input sample data for Episode 1 "Beyond Order"
  - 4 lines of God's voice narration
  - Typing effects and delay settings

### Data Structure
```csharp
[CreateAssetMenu(fileName = "New Dialogue", menuName = "Angel Kitty/Dialogue Data")]
public class DialogueData : ScriptableObject
{
    public string dialogueTitle;
    public string episodeName;
    public List<DialogueLine> dialogueLines;

    [Serializable]
    public class DialogueLine
    {
        public string characterName;
        public CharacterPosition characterPosition;
        public string dialogueText;
        public Sprite characterSprite;
        public float displayDelay;
        public DialogueEffect effect;
    }
}
```

## 5. Text Typing Effects & Integration
### Goal
Apply letter-by-letter typing effects for emotional direction and integrate all systems.

### Main Tasks
- ✅ Letter-by-letter typing effects
  - typingSpeed: Display letters at 0.05 second intervals
  - enableTypingEffect: Enable/disable typing effects
- ✅ User input processing
  - Spacebar/Click: Proceed to next line or complete typing immediately
  - ESC key: Force end dialogue
- ✅ Complete integration with NarrativeManager
  - Automate character display/background change/effect application
  - Scalable event-based system

### Typing Effect Logic
```csharp
private IEnumerator TypeText(string fullText)
{
    isTyping = true;
    mainText.text = "";

    foreach (char letter in fullText)
    {
        mainText.text += letter;
        yield return new WaitForSeconds(typingSpeed);
    }

    isTyping = false;
}
```
